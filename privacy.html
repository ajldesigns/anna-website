Privacy policy

How this website and my personal rclone app handle data. Last updated October 17, 2026.

i.

This website

annajlu.com is a static personal website. It has no accounts, forms, cookies, analytics, or advertising, and it does not collect personal information from visitors.

The site is hosted on Vercel, which may keep standard server logs, such as IP addresses and request times, for security and reliability. Fonts load from Google Fonts. Those services handle that data under their own privacy policies.

ii.

The rclone app

rclone is a Google Cloud OAuth app I set up for my own use. It lets the open source rclone tool on my computer copy and sync files in my own Google Drive.

The app is used only by me. When I sign in, Google gives rclone an access token that is stored only on my own computer. rclone uses it to list, read, upload, and update files in my Drive at my direction.

No Google user data is sent to any server I run, sold, shared with anyone, used for advertising, or used to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Access can be removed at any time from the Third party apps and services page of a Google Account, or by deleting the rclone configuration on the computer.
